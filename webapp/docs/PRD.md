## 0. 产品目标与角色

### 0.1 目标
把 AEMO 分散的公开数据，整合为澳洲电力市场参与者可决策的实时视图，
对标 ez2view（行情）/ OpenNEM（公开数据）/ Modo Energy（储能分析）。

### 0.2 用户角色与主要场景
| 角色 | 代号 | 主场景 |
|---|---|---|
| 储能运营/交易员 | TRADER | 决策充放电时点与报价、看收益排名、盯对手 |
| VPP 聚合商 | VPP | FCAS 报价策略、同行对标、组合分成核算 |
| 投资/开发 | INVEST | 储能项目财务可行性、选址收益 |
| 市场分析/研究 | ANALYST | 价格趋势、燃料结构、缺电预警、行业动态 |

### 0.3 成功度量（产品级北极星）
- 周活跃用户（WAU）、人均会话时长、人均页面查询数
- 关键页面（NEM 总览、Stations、BESS 榜）回访率
- 数据新鲜度达标率（见 NFR-2）

## 1. 全局非功能需求（NFR）

| 编号 | 需求 | 目标值 | 验证方式 |
|---|---|---|---|
| NFR-1 | API 响应延迟（热点端点） | P95 < 800ms（缓存命中 < 50ms） | 压测/日志 |
| NFR-2 | 数据新鲜度 | 5 分钟类数据滞后 < 10min；超 3× 周期标记 stale | `/api/health` data_age |
| NFR-3 | 可用性 | 单实例，目标 99%；爬虫失败不影响读 API | 监控 |
| NFR-4 | 并发 | 支持 ≥ 50 并发只读；写入（爬虫）批间让步避免锁饥饿 | 压测 |
| NFR-5 | 数据保留 | 电价 ≥12 月；竞价 14 天滚动；新闻 200 条 | DB 检查 |
| NFR-6 | 国际化 | 全 UI 中英双语切换，即时生效 | 手测 |
| NFR-7 | 浏览器兼容 | 最新 Chrome/Safari/Edge；移动端**暂不保证**（规划） | 手测 |
| NFR-8 | 数据真实性 | 真实数据标官方源；模拟数据须标 DEMO（**现状缺失，P1**） | 评审 |
| NFR-9 | 合规 | AEMO 数据须页面署名（**现状缺失，P1**） | 评审 |
| NFR-10 | 安全 | 公开部署需限流/防滥用（**现状缺失，P1**） | 评审 |

## 2. 模块 1：NEM 总览（P0）

### 2.1 概述
东部市场全景：五区域实时电价/需求、地图潮流、燃料结构、价格走势与预测、
历史回查、FCAS、热力图、天气、充裕度。所有交易决策的起点。

### 2.2 用户故事
- US-1.1（TRADER）作为交易员，我想一屏看到五区域当前电价与趋势，以便快速判断哪个区域有交易机会。
- US-1.2（TRADER）我想看到价格的官方预测线，以便预判未来 1–40 小时走势。
- US-1.3（ANALYST）我想查任意历史日的全天价格曲线，以便复盘事件。
- US-1.4（ANALYST）我想看燃料结构实时占比，以便理解价格驱动因素。
- US-1.5（TRADER）我想被提示累积价格是否接近管制阈值（CPT），以便防范 APC 风险。
- US-1.6（ANALYST）我想看未来 14 天供需充裕度与缺电预警，以便研判紧张时段。

### 2.3 功能需求
- **FR-1.1** 区域选择器支持 NSW1/QLD1/VIC1/SA1/TAS1 + WEM；切换后全页联动。
- **FR-1.2** KPI 卡展示：现货价、需求、下一区间预测价、预测需求、APC 状态。
- **FR-1.3** 地图渲染机组点（按燃料着色/形状）、联络线潮流（方向 + 颜色表征利用率）、MLF 热图层；支持拖拽（手形光标）、缩放（按钮固定）、范围限制在澳洲。
- **FR-1.4** 价格走势图支持 6h/1d/3d/7d；叠加 actual RRP、需求、AEMO 预测（P5MIN + PREDISPATCH 虚线）、绑定约束标记。
  - **预测定位说明**:页面所有"预测线"与 `/api/forecast` 均为 **AEMO 官方预调度**(P5MIN 未来 ~55 分、PREDISPATCH 未来 24–40h)。仓库根目录 `/src/` 下的 GNN-Transformer 为**独立离线研究管道,未接入线上**,不要与官方预调度混淆。
- **FR-1.5** 提供 K 线图视图（OHLC，按 30/60/120 分钟分桶），含 6h 默认窗口 + 拖动滑窗；hover 显示开高低收 + 涨跌幅。
- **FR-1.6** 历史日查询：日期选择器，范围 = 本地归档区间；返回选定日 288 个 5 分钟价格 + 当日最高/最低/均价/价差/负价区间数/>$300 区间数。
- **FR-1.7** 燃料组合实时图按燃料堆叠展示出力 + 各燃料利用率%（当前出力/装机）。
- **FR-1.8** CPT 累积价格：实时计算滚动 7 天累积 RRP，对比 $2,225,900 阈值，APC 徽章显示 未触发/接近/已触发。
- **FR-1.9** FCAS 矩阵展示 8 个辅助服务市场当前价格。
- **FR-1.10** 90 天价格热力图（横轴小时、纵轴日期、色阶价格）。
- **FR-1.11** PASA 充裕度：未来 14 天需求三分位（D10/50/90）、可用发电、LOR 等级，支持 30min/日聚合切换。

### 2.4 验收标准（节选）
- **AC-1.1** Given 选中 NSW1，When 新调度数据到达（5 分钟），Then KPI 与图在 ≤10min 内刷新且时间戳更新。
- **AC-1.5** Given K 线 1d 视图，When 数据为 288 区间，Then 默认显示首 6 小时窗口，拖动滑窗可平移到全天，hover 任意蜡烛显示 OHLC。
- **AC-1.6** Given 选择 14 个月前的某日，When 该日在归档范围内，Then 返回该日完整曲线；超范围则日期不可选。
- **AC-1.8** Given 滚动 7 天累积价格 < 阈值，Then APC 徽章显示"未触发"且为灰；≥阈值显示"已触发"且高亮。

### 2.5 交互状态
- 加载中：骨架/「加载中…」占位。
- 无数据：某燃料全程为 0 则从图例剔除；历史日无数据显示「该日期无数据」。
- 边界：负价时 K 线/曲线 y 轴跨零，显示 $0 参考线；价格触顶（$23,200）正常显示不截断。
- 错误：单接口失败不阻塞整页，对应卡片显示占位，其余照常。

### 2.6 成功指标
NEM 总览日均停留时长；历史日查询使用次数；K 线视图切换率。

### 2.7 不做（Out of scope，本期）
- 跨区域价差套利计算器；自定义指标叠加；图表导出 CSV（见规划）。

## 3. 模块 2：BESS 储能（P0）

### 3.1 概述
电池套利工作台：调度面板、模拟交易、竞价生命周期、建议报价、收益榜单、合规记分卡。

### 3.2 用户故事
- US-2.1（TRADER）我想看电池当前 SoC 与功率包络，以便决定下一步充放。
- US-2.2（TRADER）我想拿到基于价格预测的建议报价，以便快速下单（模拟）。
- US-2.3（TRADER）我想看全市场电池的收益排名，以便对标自身策略。
- US-2.4（TRADER）我想跟踪一笔报价从提交到结算的生命周期，以便理解市场机制。

### 3.3 功能需求
- **FR-2.1** 调度面板显示 SoC、功率上下限、未来 2 小时充放计划与预期收益。
- **FR-2.2** 模拟交易盘基于真实电池（WTAHB1 Waratah）：支持单档/多档报价、按交易日批量报价、撤单；结算用真实 RRP。
- **FR-2.3** 建议报价：依据 P5MIN/预调度价格 + 当前 SoC 给出充/放建议与档位；门控关闭区间禁止下单并提示。
- **FR-2.4** 收益榜单：按净收益对全澳电池排名（默认本区域，可切全 NEM；窗口 1d/3d/7d），展示放电量、卖出均价、买入均价、价差、净收益。
- **FR-2.5** 竞价生命周期时间线：展示某区间报价的状态流转。
- **FR-2.6** 合规记分卡（可展开抽屉）：规则覆盖率、待结算/已结算统计。
- **FR-2.7** 收益计算口径：放电收入 = Σ(MW>0 × 5/60 × RRP × MLF)；充电成本 = Σ(|MW<0| × 5/60 × RRP ÷ MLF)；净 = 收入 − 成本；价差 = 放电均价 − 充电均价。仅能量、不含 FCAS。

### 3.4 验收标准
- **AC-2.4** Given 收益榜 NSW1 / 24h，When 加载完成，Then 按净收益降序、前 3 名带奖牌、含价差列；切「全 NEM」后重算并刷新。
- **AC-2.7** Given 某电池当日有充有放，Then 净收益 = 放电收入 − 充电成本，且 MLF 对发电乘、对负荷除（FCAS 不参与）。
- **AC-2.2** Given 模拟报价已提交，When 目标区间出现真实出清价，Then 该报价按价格自动结算并更新累计盈亏。

### 3.5 交互状态
- 模拟盘为 DEMO（**须加标识，NFR-8**）。
- 榜单无活动电池：显示「该时段无电池活动」。
- 门控关闭：建议报价按钮禁用 + 倒计时提示。

### 3.6 成功指标
模拟报价提交数；收益榜查看/切换次数；建议报价采纳率。

### 3.7 不做
真实下单/真金交易（平台仅模拟）；FCAS 收益纳入榜单（当前仅能量口径）。

## 4. 模块 3：VPP 虚拟电厂（P0）

### 4.1 概述
聚合分布式资源的虚拟电厂运营 + 同行 VPP 报价对标。

### 4.2 用户故事
- US-3.1（VPP）我想管理组合内各资源（EV/电池）的可用性与调度，以便聚合参与市场。
- US-3.2（VPP）我想按基线核算需求响应量并与客户分成，以便结算。
- US-3.3（VPP）我想看 AGL/ShineHub/EnelX 等真实聚合商怎么报 FCAS，以便校准自身策略。

### 4.3 功能需求
- **FR-3.1** 组合视图：累计盈亏、资源清单（类型/容量/SoC/可用率/opt-in/窗口/能力）。
- **FR-3.2** 报价：能量 + FCAS，含梯形（trapezium）参数、最大可用、日能量约束、爬坡。
- **FR-3.3** 基线/分成/包络建模：需求响应量 = 基线 − 实际；按 customer_share_pct 分成；动态运行包络约束。
- **FR-3.4** 同行对标：列出有竞价活动的真实 VPP/聚合商（≥1 个市场有报价），左栏可搜索/按区域筛选。
- **FR-3.5** 对标主面板：选中机组显示 KPI（机队最大申报 MW = 近 7 天 BIDPEROFFER 峰值、参与市场数、调度侧、最新申报日）+ 市场总览表 + 选中市场的 10 档价格阶梯 + 全天带量图（6h 窗口 + 滑窗）。
- **FR-3.6** 方向语义：FCAS RAISE = 发电侧(GEN)、LOWER = 负荷侧(LOAD)，自动选择。

### 4.4 验收标准
- **AC-3.4** Given 对标页加载，Then 仅显示近 14 天有竞价的聚合商，已排除占位/燃机误匹配（DG_*/RT_*/BLNK*/DRYCGT*）。
- **AC-3.5** Given 选中某 VPP 的某 FCAS 市场，Then 显示该市场 10 档价格 + 当日全天申报量，左栏高度与主面板底部对齐。
- **AC-3.5b** Given 该 VPP 注册但近 7 天未投容量，Then 机队最大申报显示「未投放」。

### 4.5 交互状态
- VPP 遥测（EV 可用率、电池 SoC）为模拟器（**须标 DEMO**）。
- 无 SCADA：聚合资源非调度、无实时出力，页面以竞价为唯一足迹，需文案说明。

### 4.6 成功指标
对标页机组切换次数；不同 VPP/市场查看分布。

### 4.7 不做
真实 NMI 级数据、逐户结算（无数据源）；VPP 实时出力（AEMO 不发布）。

## 5. 模块 4：BESS-Calc 投资测算器（P0，已上线）

### 5.1 概述
储能项目财务可行性建模 + 历史回测 + 敏感性分析。

### 5.2 用户故事
- US-4.1（INVEST）我想输入容量/成本/融资条件得到 IRR/NPV/回收期，以便判断项目可行性。
- US-4.2（INVEST）我想用真实历史价格回测套利收益，以便验证收入假设。
- US-4.3（INVEST）我想看哪些参数对收益最敏感，以便聚焦关键假设。

### 5.3 功能需求
- **FR-4.1** 输入：功率/能量容量、RTE、退化率、扩容、capex（功率/能量/固定）、opex、WACC、负债比、税率、期限、MLF、收入项（套利价差/FCAS/CIS）。
- **FR-4.2** 输出：LCOS、项目 IRR、股权 IRR、NPV、回收期、DSCR、收入/成本拆解、现金流。
- **FR-4.3** 历史回测：选区域 + 窗口，用真实价格回算日套利收益分布（中位/P25/P75）。
- **FR-4.4** 敏感性（龙卷风图）：各参数 ±变动对核心指标的影响排序。
- **FR-4.5** 计算规则：LCOS = 全生命周期成本现值 ÷ 放电量现值；退化逐年衰减可用容量；MLF 影响能量收入。

### 5.4 验收标准
- **AC-4.2** Given 输入一组参数 + 回测窗口，Then 输出 IRR/NPV/回收期且与拆解项自洽（NPV>0 ↔ IRR>WACC）。
- **AC-4.3** Given 历史回测，Then 返回该窗口日收益的中位数与四分位。

### 5.5 交互状态
计算中显示「computing」；输入非法（负值/越界）即时校验提示并阻断计算。

### 5.6 成功指标
测算完成次数；回测使用率；参数导出/复用。

### 5.7 不做
多项目组合优化；税务细则按州差异（用统一假设）。

## 6. 模块 5：Stations 电站透视（P0）

### 6.1 概述
任意发电机组的全息档案：实时出力、元数据、当日收益、出力×价格、真实竞价带。

### 6.2 用户故事
- US-5.1（ANALYST）我想搜任意机组看其实时出力与基本信息，以便研究/监管。
- US-5.2（TRADER）我想看某机组真实的竞价带（含买卖双向），以便分析其策略。
- US-5.3（ANALYST）我想看机组当日发电量与现货收益估算，以便评估其经济性。

### 6.3 功能需求
- **FR-5.1** 左栏机组列表：~712 台，按区域/燃料筛选、按 DUID/名称搜索，显示容量与是否在地图。
- **FR-5.2** KPI：实时出力、注册容量、利用率%、MLF（含财年）、排放强度。
- **FR-5.3** 当日卡：发电量、充/耗电量、现货收入、充电成本、净收益（含口径说明）。
- **FR-5.4** 出力×价格图：5 分钟 SCADA 出力（左轴）对照区域 RRP（右轴），支持 1d/3d/7d。
- **FR-5.5** 竞价带（全宽独立行）：10 档价格阶梯 + 全交易日(288 区间)带量图（6h 窗口 + 滑窗）；电池可切买/卖方向。
- **FR-5.6** 交易日规则：04:05 → 次日 04:00；AEMO D+1 披露，默认展示最近完整交易日。

### 6.4 验收标准
- **AC-5.1** Given 列表，When 选区域 NSW1，Then 仅显示该区机组、按容量降序、已排除占位 DUID。
- **AC-5.5** Given 选中电池 + 卖电方向，Then 竞价阶梯与带量为 GEN 侧；切买电显示 LOAD 侧不同价格。
- **AC-5.5b** Given 任意机组，Then 竞价带返回完整 288 区间（04:05→04:00），不再因日历日切片只显示 4 小时。
- **AC-5.4** Given 非调度机组无 SCADA，Then 出力图显示「该机组暂无 SCADA 数据」。

### 6.5 交互状态
未选机组：主面板提示「从列表选择」。无竞价（非调度）：提示该机组不申报。

### 6.6 成功指标
机组查询数；竞价带查看/方向切换次数。

### 6.7 不做
机组级 FCAS 收益分解；跨机组对比视图（规划）。

## 7. 模块 6：News 资讯（P0，已上线）

### 7.1 概述
AEMO 官方公告 + 澳洲能源行业新闻聚合，带原文链接。

### 7.2 用户故事
- US-6.1（ANALYST）我想一处看官方公告与行业新闻，以便掌握市场动态。

## 7b. 模块 7：VPP-Calc 收益模拟器（P0，已上线）

### 概述
售前/咨询工具:回答"这个站点要不要加入 VPP"。比较三种运营模式的年度经济性,
覆盖 **C&I(工商业)** 与 **户用(Residential)** 两个场景(顶部分段切换)。

### 三模式(语义随场景平行)
- **A 无 VPP**:零售 ToU 套餐。C&I 工作时段电池 ToU 套利;户用电池做**光伏自消纳**
  (存中午富余光伏、晚高峰放给负荷)。
- **B 非工作/居家优先 VPP**:现货(spot pass-through)套餐。自用时段电池服务负荷,
  VPP 在闲时(C&I 下班后 / 户用白天外出+深夜)做现货套利放电网 + FCAS。
- **C 全程 VPP**:现货套餐;VPP 24/7 全管电池做现货套利 + FCAS。

### 估值与归因
- 套利按 **2026 年 1–5 月真实每日 5 分钟现货曲线** 估值,SoC 可行多循环(价差驱动,
  MIN_SPREAD 损耗门槛),并复用"超高价日"尾部价值面板。
- 收益分两层透明展示:**套餐切换效应**(自身负荷零售→现货,带波动风险,不算 VPP 价值)
  与 **VPP 提升**(B = 放电网套利 + FCAS;C = 自用 + 套利 + FCAS = 全部电池资产价值)。
- FR:`POST /api/vpp-calc/simulate`(入参含 `segment`),返回三模式瀑布对账 + 代表日曲线 + 超高价日。

### 待细化(规划)
- 户用 VPP 真实程序建模(固定年费补贴 vs 纯现货敞口);回收期/IRR;户用 FCAS 量级。
